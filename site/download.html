Then

The first boot takes a minute or two; then the launcher appears on the PSP. Join Wi-Fi from Settings > Network, open Apps > Packages and install a game. Logins: pi / pspexp on the Pi, cpi / cpi on the GameShell; SSH stays off until you turn it on in Settings.

The images' package lists, the GameShell's kernel and boot loader sources and earlier versions: the release on GitHub. What's new: the release notes.
